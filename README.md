# Control-Theory-Notes

这是我学习控制理论过程中整理的笔记，基于 **DR_CAN** 的视频和 **《控制之美（卷1）》**。

## 📖 主要特点

* **先问为什么**：先讲“为什么要用这个东西”，再上数学推导，拒绝干巴巴的公式堆砌。
* **物理直觉**：注重把抽象的数学公式翻译成系统的物理行为，用日常直觉去理解控制器。
* **仿真验证**：关键结论均配有 Simulink 仿真验证与踩坑记录，理论与实操结合。
