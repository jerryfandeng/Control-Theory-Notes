# Control-Theory-Notes

这是我学习控制理论过程中整理的笔记，基于 DR_CAN 的视频和《控制之美（卷1）》。

主要特点：
- 先讲“为什么要用这个东西”，再上数学推导。
- 注重物理直觉，把数学公式翻译成系统的物理行为。
- 关键结论配有 Simulink 仿真验证，理论与实操结合。
